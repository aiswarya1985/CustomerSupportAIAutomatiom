1. Streamlit UI
   Sidebar → "Ingest Knowledge Base" button clicked
       ↓
2. Streamlit calls `ingest_knowledge(clear_existing=False)` in app.py
       ↓
3. HTTP: POST http://localhost:8000/api/knowledge/ingest
   Body: {"clear_existing": false}
       ↓
4. FastAPI router — knowledge.py: ingest_knowledge_route()
       ↓
5. Depends(get_knowledge_service) → dependencies.py
       ↓
6. knowledge_service = KnowledgeService(settings=...)
       ↓
7. knowledge_service.ingest(clear_existing=False)
   (knowledge_service.py)
       ↓
8. rag_service = KnowledgeBaseService(settings=...)
   (chroma_kb.py)  ← a NEW instance, created inside .ingest()
       ↓
9. rag_service.ingest_directory(directory=..., clear_existing=...)
       ↓
10. Inside ingest_directory:
    a. If clear_existing: delete the collection
    b. Glob *.md and *.txt files
    c. For each file:
       - Read text
       - Split into chunks with RecursiveCharacterTextSplitter
       - For each chunk, compute doc_id
    d. self._collection.upsert(documents=docs, ids=ids, metadatas=metadatas)
       ↓
11. Return {"files_indexed": N, "chunks_indexed": M, "collection_count": K}
       ↓
12. Back up the chain to Streamlit
       ↓
13. UI shows: "Indexed 4 files / 4 chunks"

       customer_company=customer.get("company"),

   )
       ↓

           hits = self.memory.search(query, user_id=scope, limit=...)     ← Mem0 v3 API call
